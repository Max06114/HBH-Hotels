# Hotel Bilder für HBH-Hotels

## So verwendest du die Bilder:

1. Öffne jeden Link unten
2. Rechtsklick → "Bild speichern unter"
3. Speichere mit dem vorgeschlagenen Namen
4. Im Admin-Dashboard: Hotels → Bearbeiten → Bilder hochladen
