## Anleitung

1. Klicke auf jeden Link - das Bild wird angezeigt
2. Rechtsklick → "Bild speichern unter" → Speichere mit dem angegebenen Namen
3. Gehe zu https://hbh-hotels.vercel.app/admin
4. Login: info@travel-events.de / admin123
5. Image Manager → Bilder hochladen
6. Hotels → Bearbeiten → Bilder zuweisen
